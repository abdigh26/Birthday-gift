# Happy 21st Birthday, Hodan

A lightweight, responsive birthday page built with plain HTML, CSS, and JavaScript. It has **no framework, build step, external font request, or third-party script**, so it loads quickly and is simple to share.

## Highlights

| Area | Improvement |
|---|---|
| Performance | Uses only local assets, native browser features, and `preload="metadata"` for the video. |
| Accessibility | Includes semantic sections, descriptive media labels, keyboard-visible focus states, a skip link, and reduced-motion support. |
| Mobile experience | Uses responsive layout, fluid typography, and safe viewport sizing for small screens. |
| Interactivity | Provides a button-triggered canvas confetti effect without shipping a library. |

## Local preview

Open `index.html` in a modern browser, or serve the folder with any static file server.

## Publish with GitHub Pages

The site is configured as a static page. Once GitHub Pages is enabled for the `main` branch at the repository root, it will be available at:

```text
https://abdigh26.github.io/Birthday-gift/
```

## Updating the message or media

Edit the text in `index.html`. Replace `Assets/hodan.jpg` or `Assets/hodan.mp4` while keeping the same file names, or update the matching paths in the markup.
